# FRC Java Tutorial

Documentation site for FRC Programming, optimized for the Robolancers (team 321) and Lance-A-Lot (team 427). Knowledge check quizzes are included in the lessons to help students learn and retain information. Links are included to Github Classroom lessons for further practice/learning. The site is built with [MkDocs](https://www.mkdocs.org/) and [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

Will be updated for 2027.
